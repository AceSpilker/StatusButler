A7 / Performance（E4 深度设计）

性能监控：网速 / CPU / 内存 / GPU 实时监测

状态管家的第 4 号扩展（E4）升级为深度设计：上下行网速、CPU 使用率（含大小核分组）、内存与压力、GPU 使用率的实时监控——图标槽位、弹层曲线、桌面小组件三端同屏。登记于 A4 R-3。

本页目录 1. 功能设计（PF-01 ~ PF-30） 2. 技术方案与 API 矩阵 3. 采样纪律（能效红线） 4. GPU 监控的真实边界 5. 风险与联动

1. 功能设计（PF-01 ~ PF-30）

PF-01 网速实时监控 全机型

  • 上行/下行速率：实时 B/s—GB/s 自适应单位（1s 采样、5s 平滑可选），↕ 双行显示。
  • 按网卡分解：Wi-Fi / 以太网 / VPN 隧道（utun）分别计速并标注当前主用网卡（联动 S5 链路信息）；回环接口排除。
  • 累计流量：本次开机以来 / 今日 累计上下行量；联动 E10 落历史（按小时聚合存 30 天）。
  • 展示位：E1 图标槽位（↕ 简写速率）、弹层分区（双行大字 + 60 秒迷你走势）、A6 组件 WG-04。

PF-10 CPU 监控 全机型

  • 总使用率 + 每核心：逐核百分比（mach 处理器时钟 tick 差分），核心网格可一眼看出调度。
  • Apple Silicon 大小核分组：P 核均值 / E 核均值分开展示（性能核忙还是能效核忙，语义完全不同）。
  • 负载均衡视图：1/5/15 分钟负载均值；60 秒实时曲线 + 10 分钟趋势（E10 缓冲）。
  • 耗资源进程榜：Top 5 CPU 进程（名称 + % + 图标），点击进程可选"深入查看该进程 CPU/内存曲线"（可关，默认关）。

PF-20 内存监控 全机型

  • 用量分解：已用 / 联动锁定（Wired）/ 压缩 / 可清理，与物理总量对比（统一内存架构下 CPU/GPU 共享，明确标注）。
  • 内存压力表：系统内存压力等级（正常/警告/紧急）三色仪表——比"剩余内存"更真实反映卡顿风险（公开 API：内存压力源）。
  • Swap：交换区用量与换入换出速率；"开始使用 Swap"可提示（内存紧张的最早信号）。
  • 内存占用进程榜：Top 5 内存进程。明确不做"内存清理"类伪功能（红线：不杀进程不 purge）。

PF-30 GPU 监控 尽力支持 · 见第 4 节

  • GPU 使用率：百分比 + 60 秒曲线；Intel 独显/核显分卡显示；Apple Silicon 单卡。
  • GPU 相关联展示：GPU 温度（A5）、显存情况（Intel 独显显存用量；Apple Silicon 统一内存不单列并说明原因）。
  • 回退链：使用率不可得的机型 → 显示 GPU 功耗（mW）作为活跃度代理，再不可得 → 仅显示 GPU 温度并说明。

PF-40 阈值与提醒（联动 E10）

  • CPU 持续 > 90% 达 N 分钟、内存压力进入"警告"、Swap 首次启用 → 系统通知（全部默认关，按需开）。
  • 所有指标写入 E10 历史；弹层各分区带"历史"标签可看长曲线。

3. 采样纪律（能效红线）

  • 按需采样：所有采样器仅在其数据"有人看"时运行——对应 E1 槽位被选中、弹层分区可见、A6 组件启用、E10 落盘周期（默认 30s 一次粗采样）四类消费者任一存在；全部不可见时零采样零开销（对齐 B1 能效纪律）。
  • 采样频率分档：可见 1s（走势）/ 落盘 30s（历史）/ 槽位最小显示粒度对齐（如网速 2s 更新已足够可读）。
  • 环形缓冲：60 秒 ×1s 明细 + 10 分钟 ×5s 趋势 + E10 长期聚合，内存占用恒定（KB 级）。
  • 采样器实现为独立 actor，差分计算纯函数化（可全量单测：喂固定计数器序列断言速率）。

4. GPU 监控的真实边界（诚实设计）

macOS 没有公开的"GPU 使用率%"官方 API，各监测工具走的都是 IOKit 的 IOReport 报告体系（苹果自家工具同源）：
  • Apple Silicon：IOReport 的 GPU 利用率通道可读（非 root），数值语义接近"硬件活跃驻留比"，与任务管理器口径略有差异——UI 标注口径说明；
  • Intel 核显/独显：IOReport 通道覆盖大部分机型，个别独显只有功耗通道——按回退链降级；
  • 实现策略：机型能力探测（启动时探测可用通道并缓存结果）→ 能力矩阵决定显示什么；任何通道读取失败静默降级，绝不显示假数据。

5. 风险与联动

风险应对
IOReport 通道随系统版本调整通道探测 + 版本矩阵测试；失败降级路径已内建
进程榜与杀毒/隐私软件的兼容观感默认关、开启时说明用途；仅读取进程公开信息
高速采样被误用为常驻高耗采样纪律代码化（无消费者即停）+ 能耗自检（App 自身 CPU 占用目标 < 0.5%）
