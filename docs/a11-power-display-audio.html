A11 / Power · Display · Audio（E13 / E14 / E20 / E21 深度设计）

电池养护、显示控制与音频增强

电池养护中心（E13，C1 采纳）· DDC 亮度控制（E14，C2）· 每 App 独立音量（E20，R-5）· 一键熄屏不睡眠（E21，R-6）。登记见 A4。

一、E13 · 电池养护中心（BAT-01 ~ 04）公开 API · 守红线二

功能设计

  • BAT-01 养护总览：系统原生充电上限（Sonoma+ 的 80% 等限制）状态、优化充电学习状态、循环次数与容量健康（复用 S4 详情数据源 IOKit）；健康度趋势进 E10 历史曲线。
  • BAT-02 养护提醒：可配规则——"长期插电超过 N 天提醒拔电放电一次""容量降到 80% 提醒检修"；通知 + 事件日志。
  • BAT-03 一键直达：弹层按钮深链系统电池设置（改上限/开关优化充电在系统里完成——不写 SMC、不越权，红线二不动摇）。
  • BAT-04 养护报告：月度小结（充放电次数、平均电量区间、满电存放时长占比），纯本地统计。

二、E14 · DDC 亮度/对比度控制（DDC-01 ~ 04）复用现有 DDC 模块

功能设计

  • DDC-01 手动控制：弹层分区 + 槽位滑杆，控制外接显示器亮度/对比度（DDC/CI 寄存器 0x10/0x12），与既有音量 DDC 同面板。
  • DDC-02 快捷键与联动：F1/F2 媒体键接管外接屏亮度（可选）；内建屏随系统、外接屏跟随内建屏亮度联动（Lunar 简化版，按比例曲线映射）。
  • DDC-03 自动调光：按日出日落/时间表自动调亮暗（联动 E23 昼夜主题）；夜间最低亮度保护。
  • DDC-04 工程边界：寄存器读写失败静默降级（同 OG-FR-151 治理）；不同显示器 DDC 实现差异容错（写后回读校验、指数退避）。

三、E20 · 每 App 独立音量（PAV-01 ~ 05）可选重模块 · R-5

📌 技术结论（先说实话）：macOS 没有公开的"每 App 音量"API。eqMac / BackgroundMusic / SoundSource 的实现全部依赖同一路线——安装一个虚拟声卡驱动（苹果公开的 DriverKit 音频框架 AudioDriverKit，用户态系统扩展而非内核 kext），把系统输出接到虚拟设备，按 App 施加增益后再混音回真实设备。可行，但属于重资产：需要用户在系统设置批准驱动（管理员），与专业音频软件（Logic/虚拟声卡类）可能冲突。

功能设计（默认关闭，opt-in 安装）

  • PAV-01 混音台面板：弹层下钻页列出正在发声的 App，每 App 独立滑杆 + 静音 + 输出直通开关；App 图标 + 名称；未发声 App 折叠。
  • PAV-02 安装向导：设置中明确解释原理与影响（延迟增加约 <10ms、专业音频软件用户不建议），一键安装/卸载驱动（系统扩展同意流程）；卸载后完全恢复原状。
  • PAV-03 规则：按 App 记住音量（重启生效）；"某 App 永不超过 X%"上限规则；焦点 App 自动抬升（可选）。
  • PAV-04 直通保护：检测到专业音频软件（CoreAudio 声卡独占）运行时自动切换直通模式并提示。
  • PAV-05 工程与红线：驱动为独立 DriverKit target（可摘除）；不装驱动时功能整体隐藏不影响其他；音频数据本地处理零上传。麦克风路径不碰（只处理输出）。

四、E21 · 一键熄屏（不睡眠）（SCR-01 ~ 04）纯公开 API · R-6

📌 技术结论：完全可以，两条公开能力组合：pmset displaysleepnow（立即熄屏，无需 sudo）+ IOKit 电源断言 kIOPMAssertionTypePreventUserIdleSystemSleep（阻止系统因空闲入睡——与 caffeinate 同机制）。熄屏后下载/编译/渲染照跑，动一下鼠标/键盘即亮屏。

功能设计

  • SCR-01 一键熄屏：动作中心按钮（E2）+ 全局热键（E22）+ butler://screen/off + CLI statusbutler screen off；触发即：创建"熄屏不断电"断言 → 执行 displaysleepnow。
  • SCR-02 守护模式：可选"长任务守护"——检测到活跃下载/编译（磁盘+网络持续活动）时自动维持断言并熄屏，任务结束恢复正常睡眠策略（ caffeinate -u 思路的产品化）。
  • SCR-03 状态与恢复：弹层与组件显示"屏幕已关 · 系统运行中"徽标（点击图标/触控板即唤醒是系统行为）；断言持有期间菜单栏图标加月亮角标；App 退出/崩溃自动释放断言（恢复系统默认睡眠，不留后遗症）。
  • SCR-04 边界：笔记本合盖仍会睡眠（硬件行为，如实说明）；外接显示器熄屏时序差异容错；熄屏期间 A5 风扇/温度监控照常（这正是"熄屏不睡"的监控价值场景）。
