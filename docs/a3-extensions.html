A3 / Extension Design

扩展功能设计：超出参考项目的能力

以下 E1–E12 是为状态管家设计的原生扩展集——参考项目没有、但与其架构天然契合的新能力。每项给出交互设计、数据来源与工程/风险注记。不设优先级与阶段：这是一份平铺的扩展目录，逐项独立、任一项可砍可换；你后续加需求时（A4 登记），与某项相关的直接并入该项，无关的新开编号。

📌 全部扩展已完成深度设计（单一阶段、全量范围）：E1/E5/E6 → A8 信号槽与信息模块；E2/E3/E7/E8/E9/E10 → A9 系统控制与个性化；E4 → A7 性能监控；E11 → A5 温度与风扇；E12 → A6 桌面小组件。本页保留为速览目录。
扩展目录 E1 模块化信号槽（自定义第三个信号） E2 快捷动作中心 E3 菜单栏整理 E4 性能监控模块 E5 天气与空气模块 E6 日程倒数模块 E7 图标主题与配置分享 E8 iCloud 设置同步 E9 自动化集成（URL Scheme / Shortcuts / CLI） E10 状态历史与统计

E1 · 模块化信号槽 架构级

改动面：图标管线 + 设置 + 弹层 ｜ 数据源：见槽位清单

把图标"下部音量区"升级为可插拔槽位：用户可在设置里把下部（或追加第四段）换成其他信号源，多个信号轮换显示或手动固定。这是把"状态管家"从三合一状态工具升级为个人状态工具箱的关键扩展，也为 A4 未来需求提供标准接入位。

  • 内置槽位源：音量（默认）/ 时钟（时:分）/ 网速（实时 ↑↓）/ CPU 占用% / 内存占用% / 磁盘可用 / 电量循环详情 / 天气温度（联动 E5）/ 日程倒数（联动 E6）。
  • 槽位机制：槽位实现统一协议（标题 + 双行文本 + 0–4 级可视化值 + 图标符号 + 下钻页），新信号源只需实现协议即可进入图标与弹层——A4 新需求大多可以"以槽位形式"快速落地。
  • 轮换模式：固定单源 / 每 N 秒轮换 / 点击图标循环切换。
  • 数据源与频率：时钟每分钟对齐刷新；网速/CPU/内存 1–2s 采样（仅当选中该槽位时启动采样器，未选中不耗资源）；全部本地计算，无网络请求。

E2 · 快捷动作中心 部分依赖系统限制

改动面：弹层新分区 ｜ 数据源：系统 API / AppleScript / Shortcuts

弹层顶部增加"快捷动作"分区：一行大按钮，点击即切换系统开关，省去进系统设置的往返。

  • 可用公开方式实现的：深色/浅色外观（AppleScript tell app "System Events" to tell appearance preferences to set dark mode to …，需辅助功能授权，或读 AppleInterfaceStyle + 引导用户）、蓝牙开关（与 S7 面板同源）、Wi-Fi 开关（S5 已有）、静音（CoreAudio）、输出设备切换（S6 已有）。
  • 无公开 API 的：勿扰 / 夜览 / 舞台调度——提供跳转深链到对应系统设置面板，而不是伪装开关（诚实降级）。
  • 委托 Shortcuts：动作面板支持把任意 macOS 快捷指令钉进来（shortcuts run 或 Shortcuts Events），用户已有的自动化直接复用。
  • 按钮可自选、可排序；每个动作标注其权限需求。

E3 · 菜单栏整理 私有 API · 高风险高价值

改动面：独立子系统 ｜ 数据源：NSStatusBar 私有视图树

Bartender/Hidden Bar 类能力：把其他 App 的菜单栏图标收纳进状态管家的弹层"收纳区"，点击展开可见、平时隐藏，保持菜单栏只有一两个图标——与"管家替您打点一切"的产品人设天然互补。

  • 实现要点：遍历系统状态栏的私有视图层级取得各 NSStatusItem 的窗口引用，改变其宽度/可见性；需要每次 macOS 大版本回归验证。
  • 风险控制：独立模块（可整体摘除）+ 版本白名单（未验证的系统版本上自动禁用并提示）；绝不修改其他 App 状态，只做布局隐藏。
  • 交互：规则式（"总是隐藏 X""电量低于 20% 时显示"）+ 手动切换（点击状态管家图标两次 = 展开全部隐藏图标）。
  • 此项为全目录中工程风险最高者，接受"砍掉"或"仅做已验证版本"的裁剪。

E4 · 性能监控模块 深度设计已出（R-3）

改动面：E1 槽位源 + 弹层分区 ｜ 数据源：host_processor_info / mach_vm_statistics / sysctl / IOReport
  • 实时网速：上行/下行速率（按网卡分解：Wi-Fi/以太网/VPN 隧道），累计流量与历史。
  • CPU：总占用 + 逐核网格 + Apple Silicon 大小核分组 + Top 5 进程榜。
  • 内存：用量分解（含 Wired/压缩/Swap）+ 系统内存压力三色表 + 进程榜；不做伪"内存清理"。
  • GPU：使用率曲线（IOReport，机型差异见回退链）+ 联动 GPU 温度（A5）。
  • 采样纪律：仅"有人看"时采样（1s 可见 / 30s 落盘），全隐藏时零开销。完整设计见 A7 性能监控设计（PF-01~40）。

E5 · 天气与空气模块 需要外部 API

改动面：E1 槽位源 + 弹层分区 ｜ 数据源：定位（可选手动城市）+ 天气服务
  • 图标槽位：温度 + 天气符号（晴/雨/雪，SF Symbols 自带全集）。
  • 弹层分区：今明预报、空气质量（AQI）卡片。
  • 网络纪律（对齐红线三）：天气请求仅 https、仅白名单气象域名、请求前解析并校验目标（拒绝私网/环回地址）；位置可改手动城市避免定位权限；数据 30 分钟缓存 + 按需刷新；无网络/失败静默显示"暂无"。
  • 服务选型立项时定（如 Open-Meteo 免费无 Key 起步），供应商可替换。

E6 · 日程倒数模块 EventKit 权限

改动面：E1 槽位源 + 弹层分区 ｜ 数据源：EventKit（仅读）
  • 图标槽位："距下一件事 25 分"式单行倒数（可选只统计标注为"重要"的事件）。
  • 弹层分区：今日时间轴（未来 3 个事件 + 进行中的高亮）；点击事件打开日历。
  • 隐私：仅申请日历只读权限；标题在图标上只显示倒计时，标题仅弹层展示；可选择"只显示忙碌时段不含标题"模式。

E7 · 图标主题与配置分享 纯本地

改动面：设置中心 ｜ 数据源：本地主题文件
  • 主题文件：把 S9 外观类设置（尺寸/缩放/描边/颜色/分区编排）导出为单个 .butler-theme JSON（含版本号，带迁移）；双击导入或拖入设置窗口。
  • 内置主题库：随 App 附 6–8 套预设（极简 / 高对比 / 彩色 / 复古像素…）。
  • 分享：主题内容生成短码/文件，社区可流通；不含任何个人信息。
  • 主题应用带实时预览与一键还原默认。

E8 · iCloud 设置同步 CloudKit

改动面：设置持久层 ｜ 数据源：CloudKit 私有库
  • 多台 Mac 同步全部设置与主题（E7），登录同一 Apple ID 自动生效。
  • CloudKit 私有数据库（用户自己的 iCloud 配额），App 无法读取他人数据；无服务器运营成本。
  • 冲突策略：最后写入胜出 + 关键项（位置模式）可按设备独立。
  • 完全可选，默认关；关闭后纯本地。

E9 · 自动化集成 公开机制

改动面：App 生命周期层 ｜ 数据源：URL Scheme / App Shortcuts / CLI
  • URL Scheme：butler://volume/up、butler://bluetooth/connect?device=AirPods、butler://panel/show 等，动作与弹层按钮一一对应。
  • App Shortcuts：核心动作注册进系统快捷指令（Siri / 快捷指令 App / 键盘快捷键可触发），零配置可用。
  • CLI 薄封装：statusbutler volume 50、statusbutler status --json（输出当前快照 JSON，供脚本/状态栏工具消费）。
  • 安全：URL Scheme 动作白名单化，拒绝带参数的危险操作（不提供任何"执行任意命令"面）。

E10 · 状态历史与统计 纯本地

改动面：存储层新表 ｜ 数据源：自身监控数据落盘
  • 电池健康曲线：每日一次记录容量/循环数，绘制长期走势（本地 SQLite，仅存数值无标识）。
  • 事件日志：Wi-Fi 断连/切换记录、蓝牙设备连接/断开记录、充电时段——帮你回答"刚才怎么断网了"这类问题；默认保留 30 天，可清空。
  • 弹层入口：电池详情页与网络详情页各带"历史"标签。
  • 隐私：全部本地，永不导出，无遥测字段关联。

E11 · 温度监测与风扇控制 深度设计已出

改动面：E1 槽位源 + 弹层新分区 + 特权 Helper ｜ 数据源：SMC（AppleSMC IOKit）

对标 TG Pro / Macs Fan Control：全传感器温度监测（CPU/GPU/电池/存储/掌托…）、风扇转速监测、手动恒速与温度→转速自定义曲线控制、温度警报与日志导出。读取无特权；Apple Silicon 上写风扇需 SMAppService 特权 Helper（键白名单）。完整功能与技术设计见 A5 温度与风扇设计（TF-01~TF-30）。

E12 · 桌面小组件 深度设计已出

改动面：新 WidgetKit 扩展 target + 快照共享层 ｜ 数据源：主 App 快照文件

WidgetKit 桌面小组件（macOS 14 起摆桌面，13 放通知中心）：管家总览 / 温度 / 风扇 / 性能 / 日程 / 天气六族组件，交互式按钮（风扇模式、全速应急、静音）桌面直达，主题联动，节流 + 陈旧标注的刷新策略。完整设计见 A6 桌面小组件设计（WG-01~06）。
