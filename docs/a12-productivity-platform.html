A12 / Productivity & Platform（E15~E19 / E22~E25 深度设计）

效率与平台扩展：会议 · 脚本插件 · 体检等九项

会议助手（E15/C3）· 脚本插件槽（E16/C4 战略级）· 网络质量测试（E17/C5）· 系统健康体检（E18/C6）· 磁盘监控（E19/C7）· 全局热键（E22/C9）· 昼夜自动主题（E23/C10）· 趣味槽位皮肤（E24/C11）· App 更新扫描（E25/C12）。

一、E15 · 会议助手（MTG-01 ~ 03）

功能设计

  • MTG-01 一键入会：E6 时间轴事件解析会议链接（zoom://、meet.google、teams、tencentmeeting:// 等规则表）→ 行内"加入"按钮直接拉起对应客户端/浏览器；无链接的事件只显示。
  • MTG-02 会议中模式：到点提醒（提前 1/5 分钟可配）；加入会议后弹层顶部出现"会议条"——麦克风静音快捷（系统输入静音，公开 CoreAudio）、剩余时长、结束会议记录入 E10。
  • MTG-03 隐私：沿用 CAL-03 保守策略，默认不显标题只显"会议中"；链接解析纯本地规则，不上传。

二、E16 · 脚本插件槽（SCR-PT，战略级平台能力）C4 · 需安全设计

功能设计（SwiftBar 式，但接入槽位体系）

  • SP-01 插件形态：用户放入 ~/Library/Application Support/StatusButler/plugins/ 一个可执行脚本（shell/swift/python），按约定的 JSON 行协议输出：符号、级别 0–4、主值、副值、刷新间隔建议——即成为一个 E1 槽位源 + 弹层分区。
  • SP-02 安全沙盒（本功能生命线）：脚本以受限环境执行——独立进程、CPU/内存/运行时长配额（默认 2s 超时杀灭）、无网络、无家目录写、只读白名单参数（可配置放宽，每项显式授权）；插件损坏/超时连续 3 次自动停用并提示。
  • SP-03 插件管理页：列表（名称/作者/刷新率/上次输出/健康状态）、启停、配额调整、导入导出（.butler-plugin 包 = 脚本 + manifest，主题商店同渠道分发）。
  • SP-04 官方示例：内置 3 个示例插件（汇率、待办计数、Git 仓库状态）作为范式。

三、E17 · 网络质量测试（NETQ-01 ~ 02）

  • NETQ-01 弹层"测一下"：调用系统 networkQuality 能力（上下行/延迟/抖动/缓冲测试），结果页显示得分与历史对比（E10）；测试中明确提示会占用带宽。
  • NETQ-02 与 PF-01 关系：PF-01 是被动实时速率，NETQ 是主动诊断——诊断走系统网络栈，无自建服务器依赖。

四、E18 · 系统健康体检（HLTH-01 ~ 03）管家人设契合

  • HLTH-01 检查项（全公开 API/命令）：FileVault 是否开启、防火墙状态、Gatekeeper 状态、系统更新落后多少、Time Machine 最近备份时间、磁盘剩余空间、大版本系统新隐私特性提示。
  • HLTH-02 巡检报告：弹层分区 + A6 组件（"管家体检 92 分"）；每项带"去修复"深链对应系统设置；低于阈值项发通知（频率限制每周一次）。
  • HLTH-03 边界：只检测不代改（安全设置必须用户亲手改，这是原则不是技术限制）。

五、E19 · 磁盘活动监控（DSK-01 ~ 02）

  • DSK-01：磁盘 I/O 读写速率（公开 IOKit/统计接口）+ 各卷剩余空间与"低于 X GB 预警"；进 A7 性能面板第四张图 + E1 槽位源（磁盘剩余已有，此补 I/O）。
  • DSK-02：历史入 E10（小时聚合）。

六、E22 · 全局快捷键（HKEY-01 ~ 02）

  • HKEY-01：任意动作（弹层开关、静音、熄屏、全速应急、槽位切换、测速等）可绑全局热键；冲突检测（与系统/其他 App 抢键时提示）；录制式绑定 UI。
  • HKEY-02：默认不占用任何热键，全部用户自选（礼貌常驻）。

七、E23 · 昼夜自动主题（CRTH-01 ~ 02）

  • CRTH-01：主题（E7）可设"跟随系统外观"或"跟随日出日落"（位置复用 WX-01 城市），到点自动切换明暗两套主题；同步驱动 E14 显示器自动调光。
  • CRTH-02：切换带 3 秒预览回退（撤销窗口），防止误配。

八、E24 · 趣味槽位皮肤（SKIN-01）

  • RunCat 式动态槽位：CPU 负载驱动小动画帧率（跑猫/游鱼/齿轮），默认关；皮肤随主题商店分发，动效遵循"减弱动态效果"。

九、E25 · App 更新扫描（UPDT-01）

  • 扫描 /Applications 与 ~/Applications 的 App 清单，比对 Homebrew cask 数据源（仅 https + 域名白名单 + IP 校验，同 WX-03 纪律）提示可更新项，"去更新"深链 Homebrew 或官网；纯提示不代装。
