A2 / Feature Specification

完整功能规格 V1.0

状态管家（StatusButler）的全部功能规格：完整复刻参考项目 Status Trio 的能力（不设阶段、不设优先级——本表即全量范围），并沿用其隐私与系统权限红线。扩展的新能力见 A3 扩展功能设计；你要追加的需求登记在 A4 需求登记表，定稿后并入本页。

规格域 S1 三合一状态图标 S2 展示位置（菜单栏 / Dock） S3 弹层面板 S4 电池域 S5 Wi-Fi 与网络域 S6 音频域 S7 蓝牙域 S8 Apple 设备电池 S9 设置中心 S10 引导 / 本地化 / 无障碍 S11 更新 / 遥测 / 系统集成 S12 红线（全部功能的边界）

S1 · 三合一状态图标

OG-FR-101 自绘三合一图标

一个图标，自上而下三个区域，全部由 CoreGraphics 自绘（矢量几何 + SF Symbols，非模板图片），明暗菜单栏自动适配：

  • 上部 · 电池：百分比数字 + 充电/插头符号；充电绿色填充、系统低电量模式黄色填充、低于可配阈值红色；可选连接电源时显示百分比。
  • 中部 · 网络：Wi-Fi 信号弧 4 级；特殊态：关闭、未关联、无互联网、iPhone 热点、临时网络、互联网共享、有线连接（保留 Wi-Fi 图形的场景各自独立开关）。
  • 下部 · 音量：0–4 圆点或弧线两种样式，可整体切换；随默认输出设备切换显示对应设备分类图标。

OG-FR-102 蓝牙音频图标联动

  • 蓝牙设备播放音频时，中部图形可替换为该设备专属符号（AirPods / 耳机 / 音箱按型号映射，默认关）。
  • 音量点/弧可变蓝（默认关）；"网络错误优先"开关决定断网时网络图形与设备符号谁让位（默认开）。

OG-FR-103 充电动画

  • 充电时外环呼吸光效，开关可配；"闪电心跳"样式开关。
  • 遵循系统"减弱动态效果"；显示器睡眠时停止；提供隐藏的测试模式便于开发验证；动画帧带缓存。

OG-FR-104 渲染质量基线

  • SF Symbols 按"墨水中心"对齐（补偿符号侧轴承，带回归测试）。
  • 图标状态不变不重绘：快照相等性 + 渲染缓存 + 高频刷新合并。
  • 120×120 原始几何坐标系按比例缩放，任意 pt 尺寸不失真。

S2 · 展示位置

OG-FR-110 菜单栏 / Dock / 双开

  • 三种位置模式即时切换：仅菜单栏（LSUIElement 常驻）、仅 Dock、双开（切换为 Regular App 激活策略）。
  • Dock 图标渲染与菜单栏同一套场景状态，像素一致；任何图标改动两端同步（工程铁律，见 B1）。
  • Dock 背景：跟随系统图标风格 / 固定深色 / 浅色 / 透明。
  • 点击 Dock 图标：指针在 Dock 区域时弹弹层，否则打开设置；Dock 右键菜单含设置入口。
  • 菜单栏/Dock 右键菜单：设置、版本、退出。

S3 · 弹层面板

OG-FR-120 弹层结构与交互

  • 左键图标弹出锚定 Popover（多屏定位正确），点击外部或 Esc 关闭。
  • 分区化内容：电池 / 网络 / 音量 / 蓝牙 / Apple 设备 / 音频输入等分区，每个可独立显隐 + 拖动排序。
  • 下钻页：Wi-Fi 行 → 附近网络 + 链路详情；电池行 → 电池详情；蓝牙行就地展开设备列表（溢出时 Expand）；统一返回行。
  • 滚动调音量：弹层内滚轮调音量，作用域（仅音量控件 / 整面板）与方向（自然 / 传统）可配。
  • 页脚固定操作区（设置入口、退出等）。
  • 能效纪律：弹层可见才启动重资源（蓝牙扫描、有线链路读取、Wi-Fi 名解析），关闭即释放；打开时数据 500ms 防抖合并。

S4 · 电池域

OG-FR-130 电池概要与详情

概要（图标 + 弹层行）
  • 百分比、充电中、已接电源、充满预计时间
  • 低电量阈值（范围校验）与状态色
  • 系统低电量模式状态
  • 无电池设备（台式 Mac）的占位表现
详情页（下钻）
  • 适配器功率 W / 电压 V / 电流 mA
  • 循环次数、健康度
  • 低电量模式开关状态
  • "优化充电/充电上限暂停"状态 → 跳系统电池设置（不越权干预）

数据源：IOKit 电源描述（公开 API），事件推送 + 轮询兜底双通道（见 B1 能效策略）。

S5 · Wi-Fi 与网络域

OG-FR-140 当前网络与状态识别

  • SSID 显示（需定位授权，仅在用户开启该项或打开详情时申请）、信号 4 级、频段（2.4/5/6 GHz）。
  • 特殊状态识别：关闭 / 未关联 / 无互联网（联动网络路径监测）/ iPhone 热点 / 临时网络 / 互联网共享 / 纯有线。
  • 弹层内开关 Wi-Fi。

OG-FR-141 附近网络与链路详情

  • 附近网络列表 + 信号强度；点击网络打开系统设置的 Wi-Fi 面板（不代填密码——红线见 S12）。
  • 链路详情页：IP 配置、信道、频段、协商速率、受限网络（低数据模式）标记。
  • 以太网：有线链路状态行（速度/在线状态），下钻看地址配置，仅弹层打开且当前为有线时读取。
  • VPN 状态行（只显示，不进图标渲染键）。
  • 系统设置深跳必须落到目标面板自己的 Settings 扩展（带路由测试），Wi-Fi 齿轮 → Wi-Fi 面板而非 Network 面板。

S6 · 音频域

OG-FR-150 音量状态与操作

  • 音量等级、静音状态、默认输出设备名称 + 设备分类专属图标。
  • 弹层内：滑杆调节、滚动调节（OG-FR-120）、静音切换、音量反馈音（可选）。
  • 输出设备列表：点击切换默认输出设备；设备排序、"总是显示全部设备"、最大可见数可配。
  • 音频输入：默认输入设备、输入音量、静音（默认关，设置开启）。

OG-FR-151 外接显示器 DDC 音量 私有 API

  • 通过 IOKit IOAVService 的 I2C 读写（DDC/CI）直接控制外接显示器硬件音量，独立模块封装，可整体摘除；失败静默降级。
  • 回复时序与传输重试独立处理。

OG-FR-152 AirPods 专属能力

  • 设备型号识别（AirPods 各代 / Pro / Max）。
  • 聆听模式切换：通透 / 自适应 / 降噪（弹层蓝牙面板内）。
  • 蓝牙音频链路异常诊断展示。

S7 · 蓝牙域

OG-FR-160 蓝牙面板（默认关，首次开启申请蓝牙权限）

  • 配对设备列表：名称、连接状态、电量（IOBluetooth 配对报告为主源，pmset 配件电源报告补缺，事件驱动刷新）。
  • AirPods 左耳 / 右耳 / 充电盒三个独立电量。
  • 设备操作：点击未连接设备即连接、点击已连接即断开；键盘/鼠标/触控板/手柄先在行内确认。
  • 设备排序（拖动）、最大可见数、"幽灵设备"（系统残留）隐藏与恢复。
  • 蓝牙图标缩放（100%–180%）。

OG-FR-161 附近 BLE 设备电量（默认关）

  • CoreBluetooth 扫描广播中带电量服务的附近未配对设备；允许列表（用户勾选哪些设备显示）；仅在授权 + 蓝牙面板可见时创建扫描器，会话取消门控 + 候选缓存 + 去重合并。

S8 · Apple 设备电池（USB）

OG-FR-170 iDevice 电量 第三方协议

  • 读取 USB 连接的 iPhone / iPad / Apple Watch 电量，并入弹层"Apple 设备"分区。
  • 实现路线：锁定 commit 从源码构建 libimobiledevice 栈（openssl / libplist / glue / usbmuxd / tatsu / libimobiledevice）为独立 Helper，主 App 读 Helper 输出；依赖清单 manifest + 契约脚本（版本 / RPATH / 依赖完整性）全可执行校验。
  • 设备选择、刷新间隔、后台刷新可配；Apple Watch 支持以真机验证为准。

S11 · 更新、遥测、系统集成

OG-FR-200 自动更新（Sparkle 2）

  • EdDSA 签名 appcast；更新说明按语言分发（首发 en + zh-Hans）；含更新失败的降级驱动。

  • 仅心跳：随机安装 ID + App/macOS 版本 + 语言 + 图标位置；无姓名/账号/网络信息/硬件序列号；生产与调试构建资格分离；隐私文档公开全字段。

OG-FR-202 系统集成

  • 开机自启动（ServiceManagement 现代 LoginItem）；单实例锁（按 Bundle ID）；常驻能效纪律（见 B1）。
  • 发布流水线：GitHub Actions 全自动出包（swift test + release build → .app 组装 → 签名/公证（有证书时）→ DMG + SHA-256 → Release + appcast），本地一键脚本与 CI 同源。

S12 · 红线（所有功能的硬边界）

红线一：不读取、不存储、不传输 Wi-Fi 密码；不申请钥匙串访问。切换网络只跳转系统设置。
红线二（2026-10-12 修订，见 A5 第 7 节）：禁止任何充电/电源域的 SMC 写入与特权操作；风扇域 SMC 写入（FS! 、F{n}Md）为唯一例外，必须满足：独立模块 + 键白名单 + SMAppService 官方 Helper + 退出自愈 + 一键卸载（详见 A5 温度与风扇设计）。
红线三：隐私权限按需最小化（定位仅 SSID 显示、蓝牙仅面板开启时）；App 内一切对外请求仅限 https 且仅更新/遥测两个白名单目标；遥测默认关。
红线四：私有 API 仅限 DDC 的 I2C 通道一处，独立模块、失败即降级、可整体摘除；不引入其他未公开符号。
