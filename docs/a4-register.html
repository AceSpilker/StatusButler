登记规则

  1. 编号：R-1 起递增，一经分配不复用。
  2. 归属判定：是对复刻功能的调整 → 并入 A2 对应 OG-FR；是全新能力 → 进 A3 新开 E 编号；与 E1 信号槽契合的小功能 → 并入 E1 槽位清单。
  3. 状态流转：待评审 → 已采纳(并入A2/A3) / 需澄清 / 已拒绝(红线)。
  4. 红线预检（A2·S12）：触碰 Wi-Fi 密码 / 越权系统写入 / 新隐私权限 / 非 DDC 私有 API 的需求，登记时必须标注风险讨论结论。
  5. 表内只留一行摘要；细节写进对应规格页，避免两处维护。
