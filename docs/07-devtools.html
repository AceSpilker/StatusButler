工具用途获取方式本机状态

必须		 语言编译器 + SPM 包管理。Status Trio 要求 Swift 6；CI 锁定 6.3.3。本机注意：CLT 自带的 6.3.1 实测损坏（SPM 清单库版本混杂），已用 swiftly 装 6.4 替代 推荐 swiftly：brew install swiftly && swiftly init --assume-yes ✓ 6.4 (swiftly)

Command Line Tools
必须		 swift / clang / git / xcrun / codesign / plutil 等命令行全家桶的载体 xcode-select --install ✓ 已装
git
必须		 版本控制；SPM 拉取依赖（Sparkle）也走 git 系统自带 ✓ 2.49.0
macOS 13+ 机器

工具用途获取方式本机状态
Homebrew
建议		 macOS 缺失包管理器，下面多个工具经它安装 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" ✓ 7.0.7
Xcode（完整版，26+）
可选 · 已降级		 本项目可以完全不装：编译走 swiftly + SPM（已验证），测试走 Swift Testing 框架（已验证，不需要 Xcode 自带的 XCTest）。仅以下情况才装：想要 Xcode IDE 的图形化调试/Interface 预览、Instruments 性能分析、或想跑参考项目（status-trio）自己的 XCTest 测试套件 App Store（需免费 Apple ID）或 developer.apple.com 下载 .xip，或 brew install --cask xcodes 不装 ✓（需要时再装）

建议		 Status Trio 的 AGENTS.md 要求用 gh workflow run 做发布预检、gh run watch 跟踪 CI；日常管理 release/issue 也方便 brew install gh && gh auth login ✓ 已装（待 gh auth login 登录）
编辑器
