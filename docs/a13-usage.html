用户使用指南

面向使用者的操作手册：从安装到菜单栏、弹层、设置、槽位、命令行，以及 0.1.0 的已知限制与常见问题。设计规格请回 A2 功能规格；本文只写已随 0.1.0 实装的行为。

三十秒上手

  1. 下载 StatusButler-0.1.0.dmg（校验 .sha256 后更稳），把「状态管家」拖进「应用程序」；
  2. 首次打开：App 为 ad-hoc 签名，直接双击会被拦截——在 Finder 里右键 → 打开 → 打开，或到「系统设置 → 隐私与安全性」底部点「仍要打开」；
  3. 菜单栏出现三合一图标即安装成功；App 不进 Dock、只在菜单栏与（可选）Dock 工作。
📦 从源码构建：仓库内 statusbutler/scripts/build-app.sh release no-open 产出 dist/状态管家.app。发布说明见仓库 release-notes/0.1.0/。

菜单栏图标

  • 一个图标看三样：上中下三段分别是电池、网络、音量的当前状态，深浅色外观自动跟随系统；
  • 充电呼吸：接入电源后图标带呼吸式动效（系统开启「减弱动态效果」时自动静止）；
  • 左键＝打开状态弹层；右键＝菜单（版本号 / 设置… / 退出状态管家，设置快捷键 ⌘,）；
  • 图标大小可在设置的「状态图标外观」分区调整，并实时预览。

弹层面板

左键图标展开，六个分区一览当前快照；分区数据可见才加载——弹层关着就不采样，不看零开销：

分区内容
电池电量百分比、充放电状态（IOKit 读取）
网络Wi-Fi 名称与信号格 / 有线 / 离线，链路状态
音量当前音量与静音状态（0.1.0 中滑杆为展示；调节走 CLI / 自动化，滑杆直调随后续版本接入）
蓝牙已配对设备与电量（含 AirPods 分体仓位）
温度最高温度与风扇均速（SMC 读取）
性能CPU / 内存 / 网速当前值

设置中心

右键图标 →「设置…」打开，左栏四分区：

  • 通用：语言（简体中文 / English）、开机自动启动（0.1.0 为占位项，登录项随后续版本接入）；
  • 状态图标外观：图标大小实时预览、底部槽位选择、深浅色主题（6 套预设）；
  • 状态面板：充电指示、槽位轮换节奏等弹层行为；
  • 关于：版本信息与命令速查。

底部槽位

图标最下方的小格是信号槽：从内置源（温度、风扇转速、网速、CPU 等日租源）里选一个常驻，或在设置里选择轮换。菜单栏空间宝贵，一格只放一件事；想换就 butler slot cycle 或到设置里改。

命令行（butler CLI）

二进制随构建产出（.build/release/butler），自行复制进 PATH。查询直读主 App 快照；动作经 butler:// 转发主 App 执行：

butler status              # 人类可读快照（需主 App 在运行）
butler status --json       # 机器可读 JSON，脚本统一按 JSON 解析 stdout
butler volume 50           # 设定音量 50（主 App 经 AppleScript 落地）
butler volume up|down      # 步进；butler mute 静音
butler panel thermal       # 打开弹层直达温度分区（battery/network 同理）
butler fan 4000            # 风扇恒定 4000 RPM；butler fan auto 恢复自动
butler slot cycle          # 底部槽位轮换
butler theme apply <主题名>  # 应用主题
butler screen off          # 熄屏不睡眠
butler --help              # 全部动词 + 退出码表
退出码含义（脚本据此分支）
0成功（stdout 有载荷）
1未知命令（白名单外动词）
2快照不可用：主 App 未运行或未产出首帧；--json 模式 stdout 恒为 {"error":"app-not-running"}
3被拒（参数非法 / 越界 / 执行器拒绝）

桌面小组件 即将

六族小组件（总览 / 温度 / 风扇 / 性能 / 日程 / 天气）的数据层已就绪——主 App 持续把快照原子写入共享文件，未来扩展按同一契约读取。WidgetKit 扩展未随 0.1.0 发布，组件敬请期待下个版本（设计见 A6 桌面小组件设计）。

已知限制（0.1.0）

  • ad-hoc 签名与首开放行：无 Developer ID 证书、未公证。首启需右键打开或系统设置放行，升级新版可能需再次放行；
  • 沙盒网络限制：脚本插件槽以 sandbox-exec 禁网隔离，但 macOS 26 上 network* 拒绝规则失效、部分机型缺少该工具，此时插件降级为「无沙盒标记 + 严格超时」模式（替代方案登记 T-035b）；天气模块仅访问 Open-Meteo 白名单域（URL / DNS / 重定向三道闸）；
  • 无自动更新：Sparkle 更新链未接入，新版本手动关注 Releases；
  • 开机自启动：设置页为占位项；
  • 功能面：iDevice 电量、每 App 独立音量、弹层音量滑杆直调未含；
  • 架构：DMG 仅 arm64（Apple Silicon），Intel 请从源码构建。

常见问题（FAQ）

问题处置
双击打不开，提示无法验证开发者？正常现象（ad-hoc 签名）。Finder 右键 App →「打开」→ 再点「打开」；或「系统设置 → 隐私与安全性」底部点「仍要打开」。
菜单栏看不到图标？菜单栏图标过多会被系统折叠或挤出——移除不常用图标，或重新登录会话。
butler status 退出码 2？主 App 未运行或刚启动未产出首帧。先启动状态管家再查询；脚本侧请按退出码 2 分支重试。
CLI 输出能直接喂给 jq 吗？可以。butler status --json 是键排序的稳定 JSON；注意失败时 stdout 也是 JSON（{"error":"app-not-running"}），先看退出码再解析。
风扇控制安全吗？风扇域是产品红线里唯一的 SMC 写入白名单，带键白名单与自愈护栏；充电域硬件永不写入。详见 A5 温度与风扇设计。
它会收集我的数据吗？不会。遥测引擎默认关闭；不碰 Wi-Fi 密码与钥匙串；隐私权限最小化（红线见 A2·S12）。
小组件什么时候有？数据层已就绪，WidgetKit 扩展排在发布计划里；当前菜单栏 + 弹层 + CLI 是完整可用面。
