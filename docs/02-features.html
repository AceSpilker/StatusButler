F1 · 三合一状态图标

一个 20pt 图标承载三个实时信号 核心

Presentation/Icon/* · UI/Icon/StatusIconRenderer.swift · UI/Icon/StatusIconGeometry.swift

图标自上而下分为三个区域，全部由 App 自绘（CoreGraphics 手绘环形 + SF Symbols，非模板图片）：

  • 顶部：电池 — 百分比数字 + 充电图标 / 插头图标；充电时绿色填充，系统低电量模式时黄色填充，低于阈值（可配置）时红色；可选"连接时显示百分比"。
  • 中部：网络 — Wi-Fi 信号弧（4 级强度）；特殊状态：关闭、未关联、无互联网、iPhone 热点、临时网络（Ad-hoc）、互联网共享、有线（以太网时可选保留 Wi-Fi 图形）；蓝牙音频播放时可被设备专属符号替换（AirPods、耳机、音箱等设备模型自带符号）。
  • 底部：音量 — 0–4 个圆点或一条弧线两种样式；蓝牙设备播放时可整体变蓝；随系统输出设备切换显示对应设备图标。

细节：SF Symbols 的可见"墨水"相对布局框有侧轴承（side bearing），渲染器专门做了墨水中心对齐补偿并按符号配置缓存（Issue #30 回归测试保护）；图标渲染经过 IconRenderCoalescer 合并高频刷新；菜单栏与 Dock 走同一套场景状态（IconSceneState），保证两处像素一致。

🎨 充电动画：充电时图标外环出现呼吸/脉冲光效（ChargingEffect 系列 9 个文件），支持心跳式"闪电心跳"开关；遵循系统"减弱动态效果"（Reduce Motion，通过 ChargingEffectMotionMonitor 监听）；显示器睡眠时自动停止；带测试模式（隐藏设置）与渲染帧缓存。

F2 · 展示位置：菜单栏、Dock 或双开

三种部署形态 核心

App/AppActivationPolicy.swift · App/AppIconController.swift · UI/Icon/DockIconRenderer.swift
  • 仅菜单栏：App 以 LSUIElement（无 Dock 图标、无主窗口）常驻。
  • 仅 Dock / 双开：切换为 Regular App 激活策略，Dock 图标实时渲染同一套三合一图标；点击 Dock 图标弹出弹层或打开设置（DockActivationAction 判定指针是否在 Dock 区域、是否为 reopen 事件）。
  • Dock 背景样式：跟随系统图标风格（读取当前系统外观主题 SystemIconAppearanceTheme），或固定深色 / 浅色 / 透明。
  • Dock 图标渲染按 DockIconRenderKey 缓存（DockIconRenderCache / DockIconPreviewCache），状态不变不重绘。
  • 右键菜单（菜单栏与 Dock 通用）：设置、版本号、退出；Dock 还有独立的 AppDockMenu。

F3 · 电池域

从百分比到电池详情页 公开 API

Monitoring/BatteryMonitor.swift · Monitoring/BatteryDetailsReader.swift · Monitoring/SystemPowerReader.swift · UI/BatteryDetailsView.swift
图标/概要行
  • 百分比、充电中、已接电源、充满预计时间
  • 低电量阈值可配置 + 颜色
  • 低电量模式状态（黄色标识）

  • 低电量模式开关状态
  • "优化充电/充电上限暂停"状态 → 链接到系统电池设置（不越权干预，见概览页边界二）

F4 · Wi-Fi 域

状态、附近网络、链路详情 CoreWLAN

Monitoring/WiFiMonitor.swift · Monitoring/WiFiStatusReader.swift · Monitoring/WiFiKnownNetworkProvider.swift · Monitoring/WiFiNameAuthorizer.swift · Monitoring/WiFiNetworkController.swift · UI/WiFiNetworkListView.swift · UI/LinkDetailsView.swift
  • 当前网络：SSID 显示（需用户授权定位权限——macOS 用定位保护 SSID；WiFiNameAuthorizer 管理授权时机，仅在用户开启该显示项或打开详情时申请）、信号强度 4 级、频段（2.4/5/6 GHz）。
  • 特殊状态识别：Wi-Fi 关闭 / 未关联 / 无互联网（联动 NWPathMonitor）/ iPhone 个人热点 / 临时网络 / 互联网共享 / 纯有线连接（可配置此时是否仍显示 Wi-Fi 图形，含热点、临时、共享三种场景独立开关）。
  • 附近网络列表：扫描周围 Wi-Fi 并列出信号强度；点击某个网络会打开系统设置的 Wi-Fi 面板完成切换（刻意不代填密码，见边界一）。
  • 链路详情：IP 配置、信道、频段、协商速率、受限网络（Low Data Mode）标记。
  • 开关 Wi-Fi：弹层内可直接开关无线网卡；系统设置跳转带路由测试保护（必须落在 Wi-Fi 面板自己的 Settings 扩展，而非 Network 面板——AGENTS.md 专门规定了验证方法）。

F5 · 音量 / 音频域

从音量点到外接显示器 DDC 控制 深度功能

Monitoring/VolumeMonitor.swift · Audio/*（20 个文件）· UI/VolumeControlsView.swift · UI/AudioInputControlsView.swift
  • 音量状态：等级百分比、静音状态、当前默认输出设备名称与图标（每类设备有专属图标，AudioOutputDeviceIcon）。
  • 弹层内调节：滚轮/触控板滚动调音量，可选作用域（仅音量控件 / 整个面板）；可选"自然方向"（内容跟随手指 vs 传统滚轮方向）；滑杆调节；音量反馈音。
  • 输出设备切换：列出所有输出设备（可配置"总是显示全部设备"与最大可见数、设备排序），点击切换默认输出设备。
  • 音频输入：默认输入设备、输入音量、静音（默认关闭，需在设置开启）。
  • 外接显示器音量（DDC/CI） 私有 API：通过 DDCPrivateAPI C target 直接调用 IOKit 的 IOAVServiceReadI2C / WriteI2C 读写显示器 DDC 寄存器，直接控制外接显示器音量（DDCDisplayTransport、DDCVolumeCoordinator、DDCVolumeReply 处理时序与回复）。
  • AirPods 专属：设备型号识别（AirPodsModel）、通透/自适应/降噪聆听模式切换（BluetoothListeningMode* 系列）。

F6 · 蓝牙域

配对设备管理 + 多源电量读取 默认关闭

Monitoring/BluetoothDeviceController.swift · Monitoring/BluetoothBatteryReader.swift · Monitoring/BluetoothLEBatteryScanner.swift · Monitoring/BluetoothAccessoryBatteryEventMonitor.swift · UI/BluetoothDeviceList.swift
  • 配对设备列表（弹层面板内）：显示连接状态与电量；点击未连接设备即发起连接，点击已连接设备即断开；键盘/鼠标/触控板/手柄等 HID 设备先在行内确认（防误断）；"幽灵设备"（系统残留的已移除设备）可隐藏/恢复。
  • 电量三源合并：
    1. IOBluetooth 配对报告自带的电量（主要来源）；
    2. pmset 配件电源报告 + AccessoryPowerNotify 事件（第二来源，仅补缺）；
    3. 附近 BLE 扫描（CoreBluetooth）：扫描广播中带电量 GATT 服务的附近蓝牙设备（默认关，需蓝牙授权且弹层可见时才创建 CBCentralManager，带允许列表与会话取消门控）。
    AirPods 显示左耳 / 右耳 / 充电盒三个独立电量。
  • 图标联动：蓝牙音频播放时，中部 Wi-Fi 图形可替换为该设备专属符号（AirPods Pro、耳机、音箱各有不同符号，按设备型号映射）；音量点/弧可变蓝；"网络错误优先"开关决定断网时保留哪个信号。
  • 蓝牙音频诊断（AppleBluetoothAudioDiagnostics）：识别蓝牙音频链路异常并展示。

F7 · Apple 设备电池（USB 连接的 iPhone / iPad / Apple Watch）

自编译 libimobiledevice 读取 iDevice 电量 重资产功能

Monitoring/MobileBatteryController.swift · Monitoring/MobileBatteryHelperReader.swift · Support/mobile-battery-dependencies.json · scripts/build-mobile-battery-helper.sh

这是全项目工程投入最重的功能之一：项目从源码静态编译整套 libimobiledevice 栈（openssl 3.5.9 → libplist → libimobiledevice-glue → libusbmuxd → libtatsu → libimobiledevice 1.4.0，版本与 commit 锁定在 mobile-battery-dependencies.json），构建出独立 Helper 二进制，通过 USB 读取连接中的 iPhone / iPad / Apple Watch 电量，并入弹层的"Apple 设备"区块。

  • 设备选择、刷新间隔、后台刷新均可配置；
  • 配套 6 个校验脚本（依赖版本、clang 版本、RPATH、bundle 完整性等）；
  • Apple Watch 支持有专门调研文档（docs/apple-watch-first-read.md、docs/apple-watch-battery.md）。
复刻成本提示：此功能链路长（第三方 C 库 + Helper 进程 + 依赖锁定 + 多脚本校验），建议在复刻项目中作为独立后期里程碑，不进 P0。

F8 · VPN 与以太网

附加网络信号 公开 API

Monitoring/VPNMonitor.swift · Monitoring/VPNProbe.swift · Monitoring/NetworkConnectionMonitor.swift · Monitoring/PrimaryLinkController.swift · UI/VPNStatusView.swift · UI/EthernetStatusView.swift
  • VPN 状态行：通过系统网络扩展描述探测当前 VPN 是否生效（刻意不进入图标快照，只在弹层显示——避免污染图标渲染 key）；

  • 受限网络标记（Low Data Mode，NWPath.isConstrained）显示在网络行。

F9 · 弹层面板（Popover）

左键弹层：分区可编排的状态中心 核心交互

UI/StatusPopoverView.swift · Presentation/Panel/* · UI/PopoverWindowPlacement.swift · UI/PopoverScrollTargets.swift · UI/PopoverFooterView.swift
  • 分区化内容：电池行 / 网络行 / 音量行 / 蓝牙行 / Apple 设备 / 音频输入等分区，每个分区可独立显示/隐藏，并可拖动排序（popupSectionOrder）；
  • 下钻导航：点击 Wi-Fi 行 → 附近网络 + 链路详情页；点击电池行 → 电池详情页；蓝牙行就地展开设备列表（放不下时 Expand 控制）；带返回行；
  • 窗口定位：锚定菜单栏图标或 Dock 位置（DockPopoverPlacement），多屏处理；
  • 细节打磨：弹层打开时数据 500ms 防抖合并（popupDebounceInterval）；滚动目标区分音量控件/全面板；页脚固定操作区；弹层可见性门控了蓝牙扫描与有线链路读取（不可见即停，省电）；
  • macOS 26 玻璃外观：跟随新版系统弹层视觉（旧 SDK 构建会静默丢失，构建脚本强制 SDK ≥ 26）。

F12 · 系统集成能力

常驻、更新与统计 基础设施

App/LaunchAtLoginManager.swift · App/SingleInstanceGuard.swift · App/UpdaterManager.swift · Telemetry/*
  • 开机启动（ServiceManagement，现代 LoginItem API）；

  • 本地化：12 语言完整覆盖，含本地化键 parity 测试；App 语言可独立于系统语言选择；
  • 辅助功能：图标渲染带 Accessibility 描述（Presentation/Accessibility）。
