A9 / Control & Personalization（E2/E3/E7/E8/E9/E10 深度设计）

系统控制、个性化与自动化

快捷动作中心（E2）、菜单栏整理（E3）、主题系统（E7）、iCloud 同步（E8）、自动化集成（E9）、状态历史（E10）的完整功能与技术设计。

一、E2 · 快捷动作中心（AC-01 ~ AC-05）

AC-01 面板形态

  • 弹层顶部一行大按钮组（可多行），每动作 = 图标 + 名称 + 状态徽标（开/关/不可用灰显）；显隐与排序自定义。

AC-02 内置动作清单（诚实分级）

动作实现路线权限
Wi-Fi 开关 / 蓝牙开关 / 静音 / 输出设备切换复用 S5/S6/S7 已有通道（公开 API）蓝牙（已有）
深色/浅色外观切换读 AppleInterfaceStyle + AppleScript 写（需辅助功能授权，首次使用解释并引导）；授权拒绝则降级为深链系统设置辅助功能（可选）
勿扰 / 夜览 / 舞台调度无公开 API，只做深链跳对应设置面板（不伪装开关）无
风扇全速应急 / 恢复自动联动 A5·TF-30Helper（已装时）

AC-03~05 Shortcuts 钉选与治理

  • AC-03 浏览并钉选任意 macOS 快捷指令进面板（shortcuts run 执行，状态尽力显示）。
  • AC-04 每个动作标注权限需求；首次执行弹说明；动作失败静默提示不可用。
  • AC-05 动作与 E9 的 URL Scheme 命令同源定义（一套动作表喂三处：面板/URL/CLI）。

二、E3 · 菜单栏整理（MB-01 ~ MB-05）高风险 · 可整体关闭

MB-01~03 收纳模型与交互

  • MB-01 枚举系统状态栏其他 App 的 NSStatusItem（私有视图树），按规则把其宽度置 0（隐藏）或恢复；收纳清单显示名称 + 所属 App 图标。
  • MB-02 规则式触发："总是隐藏 X""仅电池低于 20% 显示 Y""按时间隐藏"；手动模式 = 点击状态管家图标两次临时展开全部。
  • MB-03 交互诚实设计：无法把其他 App 的菜单搬进管家弹层——点击收纳项 = 恢复该项原位供用户交互，闲置 5 秒后按规则重新隐藏（明示这一行为）。

MB-04~05 安全与版本治理

  • 系统大版本白名单：每个 macOS 大版本实机回归后才启用；未验证版本自动禁用并提示。
  • 崩溃安全：隐藏状态不持久化跨登录会话——管家退出/崩溃后下次启动先恢复全部图标再应用规则（绝不"永久吞图标"）。
  • 模块独立可摘除；设置中一键"恢复全部并关闭本功能"。

三、E7 · 图标主题与配置分享（TH-01 ~ TH-05）

TH-01~02 主题内容与格式

  • 主题覆盖：外观类全部设置（尺寸/符号缩放/描边样式/状态颜色/阈值/分区编排/槽位选择/轮换周期）；不含隐私、网络、权限类配置。
  • .butler-theme = JSON：
    { "schemaVersion": 1,
  "appearance": { "iconSize": …, "ringStyle": …, "colors": … },
  "sections":  [ … ],
  "slots":     { "footer": "netSpeed", "rotation": "5s" } }
    未知键忽略（向前兼容）+ 版本迁移函数；导入前 schema 校验与差异预览。

TH-03~05 预设、导入导出、应用

  • 内置 6 套预设：极简 / 高对比 / 彩色 / 暗夜 / 经典 Mac / 大字版。
  • 双击导入（带预览确认）、拖入设置窗口、导出为文件；分享 = 文件直传，零个人信息。
  • 应用带实时预览；一键还原默认；本机不支持的字段（如无温度传感器机型）提示跳过。

四、E8 · iCloud 设置同步（IC-01 ~ IC-04）默认关

  • IC-01 范围：设置 + 主题（E7）；历史数据（E10）不同步（纯本地）。
  • IC-02 机制：CloudKit 私有数据库（用户自己的 iCloud 配额，无服务器运营）；手动"立即同步"+可选自动。
  • IC-03 冲突：最后写入胜出，冲突时展示双方修改时间与设备名供选择；图标位置等设备相关项可设"按设备独立"。
  • IC-04 隐私：默认关闭；关闭后纯本地零云流量；CloudKit 状态异常静默降级为本地模式。

五、E9 · 自动化集成（AU-01 ~ AU-05）

AU-01 URL Scheme 命令表（butler://）

butler://panel/show | panel/thermal | panel/battery | panel/network
butler://volume/up | volume/down | volume/mute | volume/set?value=50
butler://bluetooth/connect?device=AirPods
butler://fan/auto | fan/max | fan/rpm?value=4000        ← 同 A5 动作面
butler://slot/cycle | theme/apply?name=极简
  • 白名单校验：未知命令/非法参数直接拒绝并忽略（无报错弹窗，静默日志）；与 AC-05 动作表同源。

AU-02~03 App Shortcuts 与 CLI

  • AU-02 AppIntents 注册核心动作（音量、面板、全速应急、静音、槽位切换）→ Siri / 快捷指令 / 键盘快捷键零配置可用。
  • AU-03 statusbutler CLI（独立薄封装二进制，转发 URL Scheme 到主 App）：status --json（当前快照，供脚本消费）、volume 50、fan auto、slot cycle。

AU-04~05 安全与文档

  • 只读查询 + 白名单动作；无任意命令执行面；JSON 输出仅含状态字段（无个人信息/路径）。
  • 设置页内置"命令速查"卡片（可复制）。

六、E10 · 状态历史与统计（HS-01 ~ HS-05）纯本地

HS-01~02 存储与采集

  • SQLite（应用支持目录）三张表：metric_daily（电池容量/循环数，每日一次）、event_log(Wi-Fi 断连与切换 / 充电起止 / 蓝牙连接 / 风扇模式变更 / 全部警报)、traffic_hourly（网速小时聚合）。
  • 保留策略：事件 30 天、电池健康 365 天、流量 90 天；挂现有监控器推送落盘（30s 粗采样），不新增后台采样。

HS-03~05 展示与隐私

  • 展示：电池详情页健康曲线、网络详情页日/周流量柱状、独立"事件日志"页（按类型筛选/搜索/导出 CSV）。
  • 隐私：全本地、不进遥测、一键清空；与 A5 温度历史、A7 性能历史同库同页风格。
