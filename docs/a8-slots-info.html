A8 / Slots & Info Modules（E1 / E5 / E6 深度设计）

信号槽与信息模块：天气 · 日程 · 槽位系统

E1 模块化信号槽（架构级）、E5 天气与空气、E6 日程倒数的完整功能与技术设计。至此 A3 目录中每个扩展都有深度设计页。

一、E1 · 模块化信号槽（SL-01 ~ SL-06）

SL-01 槽位架构 架构级

  • 图标下部区域升级为可插拔槽位；支持追加第四段（图标增高一档，菜单栏/Dock 自适应）。
  • 槽位协议：id / title / scene()（图标可视化）/ panel()（弹层分区）/ start() / stop()（按需启停）——新信号源实现协议即同时进入图标、弹层、组件三端。
  • 槽位注册表：内置源 + （预留）外部源注册接口；设置中的槽位选择器从注册表生成。

SL-03 可视化规范与轮换

  • 统一可视化语法：0–4 分级点 + SF Symbol + 可选等宽数字；颜色语义全 App 统一（绿正常 / 黄警示 / 红紧急，同 A5 温度、A4 电池阈值）。
  • 轮换模式：固定单源 / 每 N 秒轮换（3/5/10s）/ 点击图标循环切换；轮换淡入淡出 150ms。

SL-04~06 设置与工程

  • SL-04 槽位选择器：源列表 + 实时预览卡片；第四段独立开关；每源可配显隐细节（如时钟 24h 制）。
  • SL-05 调度纪律：SlotScheduler（actor）——槽位被选中/弹层可见/组件启用才 start()，全部不可见即 stop()（延续 B1 能效纪律）。
  • SL-06 工程落位：SlotSceneState 进入 IconSceneState.Footer（或新增 Fourth 段），渲染/缓存/测试与现有管线同构。

二、E5 · 天气与空气模块（WX-01 ~ WX-06）

WX-01 数据与定位

  • 内容：当前温度 + 天气现象（SF Symbols 全套符号）+ 今明两日预报 + AQI（空气质量指数与等级色）。
  • 位置默认手动城市（搜索/拼音匹配常见城市内置表），可选开启系统定位（申请定位权限，仅在用户明确开启时）。

WX-02 展示三端

  • 槽位：温度 + 符号（SL-02）；弹层分区：今明卡片 + AQI + 最近更新时间 + 手动刷新；A6 组件 WG-06。

WX-03 网络纪律（对齐红线三） 安全设计

  1. 请求仅 https；目标域名为编译期白名单（默认仅所选气象服务域）；
  2. 发请求前解析 DNS 并校验目标 IP：拒绝环回、私网、链路本地与保留地址；不跟随跨域重定向；
  3. 30 分钟缓存 + 槽位/面板/组件可见才刷新；失败静默显示"暂无数据 + 上次时间"，绝不重试风暴。

WX-04~06 服务与单位

  • WX-04 WeatherProvider 协议抽象：默认 Open-Meteo（免 Key）起步；带 Key 服务（和风天气等）作为可选配置项，Key 存 Keychain（此处属于用户主动存自己的密钥，不违红线一——红线禁的是 Wi-Fi 密码）。
  • WX-05 单位：°C/°F、风速单位、AQI 标准切换。
  • WX-06 睡眠唤醒按数据陈旧度决定是否立即刷新。

三、E6 · 日程倒数模块（CAL-01 ~ CAL-05）

CAL-01~02 数据与展示

  • 槽位：下一件事倒计时（25分 简写；超过 1 小时显示 1.5时；无日程显示当日日期或留空可配）。
  • 弹层分区：今日时间轴——进行中事件高亮 + 未来 3 件（时间/标题/剩余）；点击事件 深链打开"日历"App 对应事件。
  • 仅统计未来 24 小时内、非全天事件（全天事件默认不倒数，可配）。

CAL-03 隐私模式（默认最保守）

  • 默认只显示"忙碌 · 还剩 25 分"，不含标题；显示标题需在设置中明确开启；锁屏/截图场景同样遵守（槽位永远只有倒计时数字）。

CAL-04~05 刷新与范围

  • CAL-04 EKEventStore 变更通知推送 + 60 秒兜底重算；权限被拒 → 占位提示与设置引导，其余功能不受影响。
  • CAL-05 日历多选筛选：默认全部本机日历；iCloud/Exchange 日历同样支持（系统层面透明）。
📌 联动全景：SL 槽位是三端展示底座（图标/弹层/A6 组件）；WX/CAL 是首批"信息型"槽位源；网络纪律与隐私模式分别对齐 A2·S12 红线三与 A6 安全边界。工程落位见 B1 监控层 SlotSource 系列。
